# Evidencia esperada

- **ID:** TRM-0040
- **Tipo:** concepto
- **Sinónimos:** —
- **Definición:** Evidencia que la rúbrica de un objetivo de curso define, para cada nivel de logro, para mostrar el logro. Es obligatoria (mandatoria o requerida) u opcional (deseable).
- **Ámbito:** P3M (People, Product and Project Management), Área de Desarrollo
