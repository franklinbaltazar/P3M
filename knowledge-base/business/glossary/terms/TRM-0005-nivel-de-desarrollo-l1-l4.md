# Nivel de desarrollo (L1–L4)

- **ID:** TRM-0005
- **Tipo:** concepto
- **Sinónimos:** —
- **Definición:** Escala de niveles L1, L2, L3 y L4 dentro de cada seniority, que expresa niveles de desarrollo de competencias. De L4 de un seniority se pasa a L1 del siguiente (Junior a Semisenior, Semisenior a Senior).
- **Ámbito:** P3M (People, Product and Project Management), Área de Desarrollo
