# Asignación

- **ID:** TRM-0034
- **Tipo:** concepto
- **Sinónimos:** Asignación a proyecto [RCP-001:L101]
- **Definición:** Vínculo de un colaborador con un proyecto según el rol/nivel que el proyecto requiere. Lo realiza el Jefe de Ingeniería y un colaborador puede tener varias a la vez. Si el colaborador no alcanza el nivel mínimo de las competencias del rol/nivel, el portal advierte y la asignación queda pendiente hasta que se apruebe una excepción.
- **Ámbito:** P3M (People, Product and Project Management), Área de Desarrollo
